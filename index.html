Gmail בודק...
כדי לחבר Gmail:
  1. ב-Google Cloud Console → צור פרויקט → אפשר Gmail API וגם Google Calendar API (החיבור הזה כותב גם משימות ליומן שלו)

  3. הורד JSON ושמור כ-data/client_secrets.json
  4. לחץ "חבר Gmail" (אם כבר היה מחובר בעבר — יש ללחוץ שוב כדי לאשר גם את הרשאת היומן החדשה)

🗓️ ניהול זמן אישי

משימות שנשלחות לכתובת "שלי" (למטה) יקבלו שאלת הערכת-זמן בוואטסאפ וישובצו אוטומטית ביומן העסקי. שעות העבודה לפי יום מוגדרות ומעודכנות רק דרך וואטסאפ (למשל: "שלישי 9 עד 20" או "שבת סגור").
🔎 מציאת מזהה צ'אט וואטסאפ ממספר טלפון
הצ'אט מול המערכת שממנו תיענה לשאלות הערכת-זמן — לא צ'אט של לקוח. אפשר להשתמש בכלי ההמרה שלמעלה.
האירועים תמיד ייכתבו דרך אותו חשבון Google ששולח את המיילים (לא חשבון ה-Calendar הנפרד למטה) — כי זה החשבון שבטוח יש לו הרשאת כתיבה. ברירת המחדל "primary" = היומן הראשי של אותו חשבון.
כל היומנים שצריך לבדוק שאתה פנוי בהם לפני קביעת משימה — יכולים להיות מכמה חשבונות/יומנים, זה רק לקריאה ולא לכתיבה.
יש לחבר קודם את Google Calendar למעלה, ואז ללחוץ "טען רשימת יומנים".

⏰ שעות פעילות

אלה השעות שהמערכת מתחשבת בהן בפועל כשהיא משבצת משימות. ניתן לערוך כאן, וגם דרך וואטסאפ (למשל "שלישי 9 עד 20" או "שבת סגור") — שני המקומות מסונכרנים לאותה הגדרה.
